# Smart Medicine Platform — Hackathon Demo Flow Script

## 1. Overview

This document outlines the step-by-step presentation demonstration for hackathon judges.

---

## 2. Phase 1: Manufacturer & Batch Creation (Web Panel)
* **Presenter**: Member 2
* **Action**: Log into Web Admin Panel (`http://localhost:3000`).
* **Highlight**: Create a new medicine entry & manufacturing batch. Trigger DataMatrix code generation.

---

## 3. Phase 2: Packaging Layout Optimization (Layout Engine)
* **Presenter**: Member 3
* **Action**: Show automatic layout preview rendering for the medicine packaging box.
* **Highlight**: Show SVG preview with optimal QR placement, high accessibility text scaling, and cost score.

---

## 4. Phase 3: Accessible Mobile Verification (Mobile App)
* **Presenter**: Member 4
* **Action**: Open Flutter app on Android device. Use voice gesture to trigger scanner.
* **Highlight**: Camera scans DataMatrix on package. App speaks medicine details, dosage, and authenticity status via TTS. High-contrast UI and haptic vibration feedback.

---

## 5. Phase 4: Voice Assistant Interaction
* **Presenter**: Member 2 & 4
* **Action**: Ask the voice assistant questions about medicine interactions and storage instructions.
* **Highlight**: Natural AI voice response provided seamlessly across both web and mobile platforms.
